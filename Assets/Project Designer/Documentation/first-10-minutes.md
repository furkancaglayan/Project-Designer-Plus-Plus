# First 10 Minutes

This guide is for the first short session where you want to understand what Project Designer+ is good at without reading everything first.

## Minute 1: Open the right surface

- Open `Tools/Project Designer/Onboarding` if you want a guided first-use flow.
- Open `Tools/Project Designer/Project Finder` if you want to reopen an existing board.
- Open `Tools/Project Designer/Open Planner` if you already know which board you want to edit.

## Minute 2: Start from a useful board

Choose one of these if you want to understand the product quickly:

- `Project Designer+ Redo Board`
  Best showcase board for planner depth, saved views, milestone flow, and launch prep.
- `Milestone Roadmap Board`
  Best quick introduction to sequencing and checkpoints.
- `Research & Reference Board`
  Best quick introduction to notes and reference capture.

## Minute 3: Learn the three board actions

- Drag cards to organize work.
- Drag from `Link` on a card to create relationships.
- Right-click empty canvas or selected cards for fast actions and arrangement tools.

## Minute 5: Switch views

Use `Saved Views` on the left to see how one board can support different conversations:

- roadmap
- risks
- references
- launch prep
- team workload

## Minute 7: Edit a task

Select a task card and change:

- title
- description
- assignee
- status

Then open `Advanced` if you want due date, estimate, priority, acceptance criteria, and tags.

## Minute 9: Use one insight

Open the bottom `Insights` strip and click:

- `Blocked`
- `Due Soon`
- `Overdue`
- `Unassigned`
- `At Risk`

That is the fastest way to see how the planner moves from a board of cards to a board of planning signals.

## Minute 10: Open the samples

Look in:

- `Assets/Project Designer/Samples/ShowcaseBoards`
- `Assets/Project Designer/Samples/StatusReportExtension`

Use those when you want stronger demo content or a concrete extensibility example.
