# Sample Boards

Project Designer+ includes boards that do two different jobs:

- starter boards for real project work
- showcase boards that demonstrate what the planner can handle

## Best Starting Points

- `New Board`
  Light starting point with a pinned `Project Brief` card.
- `Milestone Roadmap Board`
  Good default for planning checkpoints, scope, and dependencies.
- `Research & Reference Board`
  Good default for inspiration gathering, decision capture, and source organization.
- `Stakeholder Review Board`
  Good default for demo prep, risks, and review asks.

## Showcase Boards

- `Project Designer+ Redo Board`
  Flagship showcase board for planner architecture, rollout work, docs, samples, and launch prep.
- `Solo Indie Board`
  Denser single-person planning example.
- `Small Team Board`
  Cross-discipline example for design, production, engineering, and art.
- `Technical Design Board`
  Optional technical-design example that keeps class cards secondary to planning.

## Included Sample Folders

Look in:

- `Assets/Project Designer/Samples/ShowcaseBoards`
- `Assets/Project Designer/Samples/StatusReportExtension`

Those folders are already included with the asset. No separate sample import step is required.

## How To Use The Samples Well

- open a showcase board first
- switch through the saved views
- click cards and inspect the right-side editing flow
- use `Arrange > Auto Layout Left To Right`
- try right-click context actions
- inspect how references, milestones, tasks, and technical cards coexist

## Best Boards For Different Goals

- Want a product demo: `Project Designer+ Redo Board`
- Want roadmap planning: `Milestone Roadmap Board`
- Want research/reference capture: `Research & Reference Board`
- Want a team-planning example: `Small Team Board`
- Want an extensibility example: `Status Report Demo Board`
