# Changelog

## 3.0.0

Project Designer+ has been fully rebuilt as a planning-first Unity editor tool.

- Repositioned the product as a node-based pre-production planner for indie teams.
- Added a new planning workflow built around Planning Boards, cards, saved views, Project Finder, and onboarding.
- Reworked the built-in card set: Task, Milestone, Note, Reference, Project Brief, and optional Class cards.
- Added project-wide team roster support for assignee selection and workload summaries.
- Added board insights for workload, blocked work, due soon, overdue, milestone health, and risk visibility.
- Added saved views, quick filters, search, category filtering, and clearer active view handling.
- Added multi-selection, duplicate, frame, align/distribute, and smart auto-layout tools.
- Added onboarding templates, showcase boards, and sample extension content.
- Improved extensibility with registry-based nodes, edges, inspectors, and importers.
- Improved usability with calmer UI, collapsible panels, context actions, and stronger board navigation.
- Updated documentation and package structure for the rebuilt version.
- Not compatible with previous versions.
