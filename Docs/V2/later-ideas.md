# Later Ideas

These ideas were intentionally left out of `3.1.0` so the update could stay small and focused.

## Workflow Ideas

- Duplicate board from Project Finder or board-level actions.
- Add an `Open Last Board` shortcut or a `Resume Last Board` start action.
- Add more board actions in Project Finder such as `Reveal In Project` or `Open Folder`.

## Saved View Ideas

- Prompt for a saved view name when creating a new one instead of relying on generated names.
- Add saved-view reordering or favorites inside the board.
- Support richer saved-view criteria such as required tags or visibility rules.

## Reference Ideas

- Create a reference card directly from a clipboard URL.
- Add a quick action to use the linked asset name as the card title.
- Add lightweight preview thumbnails or richer media handling for reference cards.
