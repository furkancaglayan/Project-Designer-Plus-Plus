## Overview

Project Designer+ is a planning-first Unity editor tool built around node-based boards. It is designed for early project work like milestone mapping, task planning, reference gathering, project briefs, and lightweight technical design.

## Workflow

The tool includes onboarding, starter templates, workflow presets, and showcase boards so you can begin from a useful structure instead of an empty canvas. Project Finder helps reopen current boards quickly, while drag-and-drop asset capture makes it easy to turn Unity assets into planning references.

## Built For Unity

Project Designer+ ships as a regular Unity asset and is tailored for in-editor use. Boards live alongside your project, and built-in layout tools such as multi-select, align/distribute, and left-to-right auto layout help keep dense boards readable.

## Extensibility

The current version also exposes extension hooks for custom cards, inspectors, links, and importers. That makes it possible to adapt the planner to studio-specific workflows without patching the core package.
