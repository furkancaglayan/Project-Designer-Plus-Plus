# Showcase Boards Sample

This sample gives you a built-in demo board that is dense enough to inspect, present, and reuse as a product reference.

## What To Open

After importing the sample from Package Manager, open `Project Designer+ Redo Demo Board.asset`.

Use that board to inspect:

- how a real planner board can carry product rewrite work, docs, rollout prep, and technical notes together
- how milestone, dependency, reference, and technical links read when a board is actually busy
- how `Project Brief`, task, note, reference, and class cards can coexist without turning the planner into a UML-only surface
- how saved views like `Core Planner`, `Launch`, `Samples`, and `Polish` help cut through a denser board

## Good Uses

- screenshot and trailer capture
- onboarding walkthroughs
- team reviews of planner depth
- a reference board when shaping your own sample content
