# Sample Boards

Project Designer+ ships with four built-in board presets.

## Empty

Use when you want a blank board plus the built-in templates and starter filters.

Best for:

- teams with an established planning process
- custom package consumers
- extension developers

## Solo Indie

Focuses on:

- player fantasy
- vertical-slice planning
- fast reference capture
- one-person ownership

Best for:

- solo developers
- early prototypes
- pitch discovery work

## Small Team

Focuses on:

- shared feature pillars
- milestone alignment
- design, art, engineering, and production coordination

Best for:

- small internal teams
- contractor coordination
- stakeholder review prep

## Technical Design

Focuses on:

- class structure
- implementation notes
- technical dependency mapping

Best for:

- architecture discussions
- tool planning
- technical breakdowns that should stay secondary to the main planning experience
