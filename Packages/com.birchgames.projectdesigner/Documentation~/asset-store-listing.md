# Asset Store Listing Draft

## Short Positioning

Project Designer+ is a node-based pre-production planner for indie Unity teams.

## Description Draft

Project Designer+ helps you plan game pre-production inside Unity instead of splitting work across disconnected whiteboards, note apps, screenshots, and technical docs.

Build milestone-driven boards, track tasks with assignees and estimates, keep references next to planning decisions, and capture technical design when you need it without turning the whole tool into a UML product.

The package includes:

- a UI Toolkit workspace with a custom graph canvas
- built-in planning nodes for tasks, milestones, notes, references, and technical class nodes
- asset drag-drop importers for scripts, text assets, sprites, and textures
- starter boards for solo devs, small teams, and technical design sessions
- public extension hooks for custom nodes, inspectors, edges, and asset importers

## Key Features

- Milestone and task planning in a board-native workflow
- Search, category filtering, and saved board filters
- Drag Unity assets into the canvas to create planning references
- Command-stack-based editing for undo, redo, persistence, and testing
- Public registry for extending the package without modifying core code

## Audience

- solo game developers
- indie teams
- small internal prototypes
- technical designers and tools engineers who need an extensible planning surface
