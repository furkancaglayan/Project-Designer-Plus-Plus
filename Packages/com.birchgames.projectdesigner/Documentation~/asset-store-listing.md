# Asset Store Listing Draft

## Short Positioning

Project Designer+ is a node-based pre-production planner for indie Unity teams.

## Description Draft

Project Designer+ helps you plan game pre-production inside Unity instead of splitting work across disconnected whiteboards, notes, screenshots, and technical docs.

Build milestone-driven planning boards, track tasks with assignees and estimates, keep references next to planning decisions, and capture technical design when you need it without turning the whole tool into a UML-only product.

The package includes:

- a UI Toolkit planner with a custom board canvas
- a dedicated `Planning Boards` browser for opening and creating boards
- built-in planning cards for tasks, milestones, notes, references, and technical class cards
- workflow presets for pitch, roadmap, research, and stakeholder review
- richer showcase boards for solo, small-team, and technical planning scenarios
- asset drag-drop importers for scripts, text assets, sprites, and textures
- public extension hooks plus a sample extension with a demo board

## Key Features

- milestone and task planning in a board-native workflow
- search, category filtering, and saved views
- drag Unity assets into the planner to create reference or class cards
- command-stack-based editing for undo, redo, persistence, and testing
- public registry for extending the package without modifying core code

## Audience

- solo game developers
- indie teams
- small internal prototypes
- technical designers and tools engineers who need an extensible planning surface
