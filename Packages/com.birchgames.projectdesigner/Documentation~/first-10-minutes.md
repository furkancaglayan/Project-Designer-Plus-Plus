# First 10 Minutes

## 1. Create a Starter Board

Create either:

- `Solo Indie Board` for a one-person project
- `Small Team Board` for shared planning
- `Technical Design Board` for architecture mapping

## 2. Establish the Goal

Select the board background and fill in:

- board name
- one-paragraph summary
- team directory

Keep this short and decision-focused.

## 3. Review the Seeded Nodes

Starter boards create a few initial nodes so you can edit instead of starting from a blank canvas.

- update the first milestone
- rename the seeded tasks
- rewrite the reference or note nodes so they match your project

## 4. Add Real Inputs

Drag a few assets onto the board:

- one script
- one image or sprite
- one text asset if available

This exercises the importer pipeline and helps validate whether the board is useful for your real project material.

## 5. Create Your First Links

Use the right inspector on a selected node to create:

- task to task dependency links
- task to milestone links
- reference links to planning nodes

## 6. Save a Filter

Use the toolbar search and category filter, then save the result as a named filter from the toolbar.

Suggested first filters:

- `Planning`
- `References`
- `Technical`

## 7. Decide Whether It Fits Your Team

At the end of the first pass, ask:

- does this make pre-production decisions easier to discuss?
- does asset drag-drop save time versus a separate tool?
- do the built-in node types match our real workflow?
- do we need a custom node or importer?
